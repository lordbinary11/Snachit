# Snachit Mobile

A React Native app built with Expo and Expo Router.

## Start the app

- `npm install`
- `npx expo start`

Use the Expo terminal shortcuts to launch iOS, Android, or web.

## Routes and source

- `src/app/` contains file-based routes.
- `src/components/` contains reusable screen components.
- `src/constants/` contains shared design tokens.
- `src/utils/responsive.ts` contains viewport-aware font and dimension helpers.
- `assets/figma/` contains local assets exported for implemented screens.

The first route redirects to the sign-in screen at `/(auth)/sign-in`.
